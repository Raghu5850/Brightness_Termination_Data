# Brightness Termination Data Analysis

## Project Overview

This project focuses on analyzing and processing Brightness
Termination data using Microsoft Excel.

The project contains the input dataset, processed output data,
and supporting documentation to demonstrate the complete
data-processing workflow.

## Project Objectives

- Analyze Brightness Termination data
- Clean and validate the input data
- Process the required business rules
- Generate the expected output data
- Identify data inconsistencies and exceptions
- Present the processed results in a structured format

## Files Included

### Input
`Brightness_Termination_Input_Data.xlsx`

Contains the original input data used for the analysis.

### Output
`Brightness_Termination_Output_Data.xlsx`

Contains the processed and final output data.

## Tools Used

- Microsoft Excel
- Excel formulas
- Data Cleaning
- Data Validation
- Data Analysis

## Project Workflow

1. Import the input data
2. Understand the dataset
3. Clean and validate the data
4. Apply the required business rules
5. Process the termination data
6. Generate the output
7. Validate the final results

The project successfully processes the Brightness Termination
